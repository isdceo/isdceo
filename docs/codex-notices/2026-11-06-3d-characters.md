# 슈슈 팀(Codex) 요청 — 리그 캐릭터 14명 3D로 다시 그리기 (2026-11-06)

리그 공용 캐릭터 14명을 3D 애니메이션 영화 느낌으로 바꾸려고 합니다. 이미지 생성을 슈슈 팀에 부탁드립니다. 두 팀 화면이 같은 캐릭터를 쓰니, 만든 그림은 양쪽에서 함께 씁니다.

## 진행 순서

1. **시안 2장 먼저**: 뚝심이(1번)와 알짜(7번)를 만들어 운영자에게 보내 주세요. 화풍과 크기를 테이블에 맞춰 본 뒤 운영자가 진행 여부를 알려 드립니다.
2. 확정되면 나머지를 **같은 세션에서 한 번에** 만들어 주세요. 그래야 화풍이 고르게 나옵니다. 현역 10명(1~10번)이 먼저이고, 대기 4명(11~14번)은 나중에 해도 됩니다.
3. 결과는 운영자에게 전달해 주세요. 운영자가 저장소 `league/agents/avatars/3d/<영문이름>.png` 로 올립니다(예: `3d/ttukshim.png`). 로로 팀(Claude)이 자르고 압축해서 명패·쪼이기 창·프로필에 넣습니다.

## 꼭 지킬 것

- **실존 인물을 닮지 않게** 해 주세요. 특히 투자 스타일과 연결된 실존 투자자를 떠올리게 하는 얼굴·안경·머리 모양은 피해 주세요. 지난 대시보드 검토(2026-11-06-dashboard-review.md 1번)와 같은 기준입니다. 닮아 보이면 버리고 다시 만들어 주세요.
- 운영자가 보낸 참고 그림은 **화풍만** 참고합니다. 참고 그림 속 인물을 따라 그리지 않습니다.
- 그림 안에 글자·로고·브랜드가 없어야 합니다.
- 쓰는 이미지 생성 도구의 약관에서 **만든 그림을 지인에게 보여 주는 화면에 써도 되는지** 확인해 주세요. 확인 결과를 함께 알려 주시면 됩니다.
