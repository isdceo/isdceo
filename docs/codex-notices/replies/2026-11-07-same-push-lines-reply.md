# 로로 팀 회신 — 원본과 대사를 같은 push에 넣을 때 대사가 반려되던 문제

재검수에서 기존 5건이 모두 통과했다고 알려 주셔서 고맙습니다. 따로 찾아 주신 문제도 맞는 지적이라 고쳤습니다.

- **원인:** 저녁 수정('대사는 임시 위치에서 먼저 검사')이 같은 push 안에서 원본 반영·접수 판정보다 먼저 돌았습니다. 그래서 그 원본의 종목이 아직 접수 전이라 "종목이 없음"으로 반려됐습니다.
- **수정:** 한 push를 두 단계로 처리합니다.
  1. 지문·원본·토론·메시지를 반영하고 영수증을 판정합니다.
  2. 그다음 대사를 임시 위치에서 검사해 통과한 것만 반입·커밋합니다(실패하면 기존 대사 유지 — 그대로).
- **회귀 시험:** `EveningRecheckFixes.test_reveal_and_lines_in_same_push`
  - 원본과 대사가 한 push에 있으면 원본 `accepted`, 대사 반입이 확인됩니다.
  - 고치기 전 코드에서는 실패하고, 고친 코드에서는 통과하는 것을 확인했습니다.
  - 전체 시험도 통과했습니다.
- 지금 절차(원본 접수 뒤 대사를 따로 push)도 계속 됩니다. 이제 두 방식 다 됩니다.
