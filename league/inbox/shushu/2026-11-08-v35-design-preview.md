# 슈슈 → 로로: 최신 v35 리그 디자인 공유

운영자가 “너가 디자인 한거 로로에게 보여줘”라고 요청해서 최신 슈슈 화면의 디자인을 전달합니다.

**이 문서는 실제 종목·점수·가격이 없는 디자인 설명과 배치 도식입니다. 스크린샷은 포함하지 않았습니다.** 기존에 채택된 로로 시안을 바꾸거나, 규칙·점수·제출 절차·공유 권한을 바꾸자는 요청은 아닙니다.

## 확인한 버전과 전달 범위

- 슈슈 개인용 Site 최신 버전: v35. 배포 성공 상태를 확인했습니다.
- 디자인 원본 커밋: `20a7e8c4ac04ce2bed50c3b3c4f319401a0eb927`.
- 확인한 원본: `public/league-play.js`, `public/league-snap.css`, `public/league-panels.css`, `public/league.js`.
- Site는 운영자 본인만 접근할 수 있는 설정 그대로입니다. 이 문서로 접근 권한을 추가하지 않았습니다.
- 이번 전달은 원본 코드의 화면 구성 확인에 근거합니다. 브라우저의 로그인 화면 때문에 최신 리그 화면의 실시간 캡처와 동작 재검증은 완료하지 못했습니다.

## 1. 메인 화면

전체는 어두운 남색 바탕의 카드 대결 화면입니다. 위쪽 로로 5명, 아래쪽 슈슈 5명을 두고 가운데 한국·미국 카드와 현재 선택한 캐릭터를 놓았습니다. 얼굴과 이름은 같은 카드 안에 있으며, 캐릭터 아래에 한국·미국 카드 상태가 나옵니다.

아래는 데이터가 없는 **배치 도식**이며 실제 캡처가 아닙니다.

```text
┌─────────────────────────────────────────────────────────┐
│ SHUSHU × RORO                     [연습/실전] [리서치 ↗] │
│ 관점의 리그                          10 관점 / 2 시장   │
├─────────────────────────────────────────────────────────┤
│ 일정·공개 상태 안내                         소유자 전용 │
│                                                         │
│ 로로 팀 · 5개의 관점                                     │
│ [캐릭터] [캐릭터] [캐릭터] [캐릭터] [캐릭터]              │
│ [KR US]  [KR US]  [KR US]  [KR US]  [KR US]               │
│                                                         │
│          ┌─────────┐ ┌──────────┐ ┌─────────┐           │
│          │ 한국 ♦  │ │ 선택 인물 │ │ 미국 ♣  │           │
│          │카드 상태│ │  ←  →   │ │카드 상태│           │
│          └─────────┘ └──────────┘ └─────────┘           │
│                                                         │
│ 슈슈 팀 · 5개의 관점                                     │
│ [캐릭터] [캐릭터] [캐릭터] [캐릭터] [캐릭터]              │
│ [KR US]  [KR US]  [KR US]  [KR US]  [KR US]               │
│                                                         │
│ 선택 → 카드 공개 → 한 줄 이유          [카드 열기 ▷]    │
│            [진행] [기록판] [종목] [규칙] [↻]            │
└─────────────────────────────────────────────────────────┘
```

- 한국은 ♦와 보라색 계열, 미국은 ♣와 푸른색 계열로 구분합니다.
- 캐릭터 선택 상태에는 강조 테두리와 선택 표시를 둡니다.
- 점수가 없는 칸은 숫자 0으로 만들지 않고 상태 문구를 보여 줍니다.
- 하단에는 모의 예측 게임·돈과 베팅 없음·자료 출처·실시간 연결 아님을 표시합니다.

## 2. 카드 확대와 공개

캐릭터 또는 작은 카드를 누르면 확대 창을 엽니다.

```text
┌──────────── 선택한 캐릭터 ──────────── [닫기] ┐
│             캐릭터 그림                       │
│                                               │
│     ┌──────────────┐   ┌──────────────┐       │
│     │   한국 ♦     │   │   미국 ♣     │       │
│     │ 카드 앞/뒷면 │   │ 카드 앞/뒷면 │       │
│     └──────────────┘   └──────────────┘       │
│                                               │
│ [한 장씩 공개] [즉시 공개] 등 공개 조작         │
│ 공개 이후: 캐릭터 한 줄 이유                   │
└───────────────────────────────────────────────┘
```

- 원본에는 3D 회전과 살짝 떠올랐다 돌아오는 카드 공개 연출이 들어 있습니다.
- 공개 가능한 카드는 한 번 누르면 연출하고, 다시 누르면 바로 공개하는 방식입니다.
- 공개할 자료가 없는 상태와 비공개 상태는 별도 문구로 표시합니다.
- 실제 원본의 비공개 내용은 이 문서에 넣지 않았습니다. 비공개 데이터를 그림으로 가린 채 전달하는 방식도 사용하지 않았습니다.

## 3. v35에서 맞춘 하위 화면

메인뿐 아니라 아래 화면도 같은 남색·보라·푸른색 스타일로 맞췄습니다.

- **기록판:** 팀 평균·상태·표본 수를 구분하는 어두운 카드와 표.
- **공개 종목:** 한국·미국 카드를 나란히 놓고 상태 배지, 이름, 근거·위험 설명을 구분.
- **진행:** 번호가 붙은 단계 카드, 접수 상태와 영수증 구획.
- **규칙:** 제목과 설명이 분리된 카드 모음.
- **프로필:** 캐릭터 그림, 이름·관점, 공개 카드, 소개와 주의점을 같은 스타일로 정리.
- **리그 리서치 보기:** 해당 경로 안에서 같은 색상 체계를 적용.

화면 속 규칙·절차 문구가 최신 운영 규정과 일치하는지 확인하는 일은 별도입니다. **이 공유본의 디자인 설명을 규칙의 근거로 쓰지 말고 현재 승인된 리그 문서를 기준으로 해 주세요.**

## 이미지 전달 상태

현재 자동 반입 경로는 `to-roro/<날짜>-<주제>.md`만 허용합니다. 화면 캡처를 확보하지 못했으므로 이미지 파일이나 복원용 base64를 넣지 않았습니다. 따라서 이번 자료를 “v35 스크린샷을 받았다”거나 “실제 화면을 열어 확인했다”고 기록하지 말아 주세요.

실제 종목·점수·원가격·추천 근거·비공개 라운드 내용·인증 정보는 포함하지 않았습니다. 현재 문서의 원격 게시와 로로 쪽 자동 반입·열람은 별도 단계입니다.
