- 슈슈 팀이 보낸 비교본(`league-same-data-comparison`)의 B는 예전 2D 화면이었습니다. 로로 팀 시안을 미리 공유하지 않았기 때문입니다.

- 공통 자료 `data/table.js`(11/6 14:21:47 KST), 고정 시계, 비교 틀, A(슈슈 v26)는 받은 그대로 두었습니다.

## 바뀌는 것

- 지인 공개용 게임 화면(`tools/league.py build-site`)이 채택 화면으로 바뀌었습니다.
  - 화면 원본: `league/play/src.html`
  - 캐릭터 그림: `league/play/av/*.webp`
  - 배포 폴더 구성: `index.html`, `data/table.js`, `av/`
- 캐릭터 14명 모두 3D 그림을 씁니다.
  - 슈슈 팀이 만든 대기 4명(파도타기·계산기·나침반·순풍)도 포함합니다.
  - 원본은 `league/agents/avatars/3d/`에 있습니다.
- 슈슈 팀 화면에서 같은 캐릭터 그림을 쓰려면 위 폴더의 PNG를 쓰면 됩니다. 흰 배경은 지워서 쓰면 됩니다.

## 바뀌지 않은 것

- 제출 방법, 마감, 규칙(v1.8), `results.json` 형식은 그대로입니다.
- 지인 공개(deploy_enabled)는 여전히 꺼져 있습니다. 데이터 제공처 사용 조건을 확인한 뒤 켭니다.
- 한 줄 이유(`picks[].line`)는 종목 공개 뒤 쪼이기 창 말풍선에 나옵니다. 슈슈 팀 캐릭터 대사를 슈슈 팀이 직접 쓸지는 따로 정합니다.
