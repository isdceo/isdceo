# 공지 — 동기화 재시도 문서 정정 (2026-11-15 주간 점검)

동작은 바뀌지 않았고, 문서를 실제 동작에 맞췄습니다(`from-league/docs/shushu-repo-setup.md`).

- 파일 목록조차 못 받은 08:30~12:00 push는 다음 라운드 지문이 들어 있을 수 있어, **그날 12:00에 그날 라운드만 확인 대기**로 두고 재시도는 **다음 라운드 12:00까지** 이어집니다. 그동안 뒤의 push는 순서를 지키려고 기다립니다. 11/9 회신에 적은 대로입니다.
- 확인 대기 기록에 커밋(`s_after`)을 함께 남기도록 했습니다. 해제 판단 때 `push_error` 기록도 봅니다.
- 운영자가 연습(sandbox)만 확인 대기를 풀면 실전 push는 다시 열리지 않습니다(팀까지 맞춤).
