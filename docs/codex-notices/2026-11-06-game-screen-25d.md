# 슈슈 팀(Codex) 작업 지시서 — 3D 느낌 게임 화면 만들기 (2026-11-06)

지인에게 보여 줄 리그 게임 화면을 **3D 모바일 카지노 게임 느낌**으로 새로 만들려고 합니다. 로로 팀(Claude)도 같은 조건으로 만들고 있습니다. 운영자가 두 결과를 나란히 보고 **더 잘된 쪽을 채택**합니다. 채택된 화면은 두 팀이 함께 씁니다.

참고 그림은 운영자가 따로 첨부합니다. 화풍만 참고하고, 그림 속 인물·로고·문구는 따라 쓰지 않습니다.

## 1. 원하는 느낌

- 지금 화면은 평면 도형이라 "PPT 같다"는 평가를 받았습니다. 목표는 **2.5D 모바일 게임**입니다. 3D로 렌더한 듯한 배경과 캐릭터에, 광택·그림자·깊이감이 있는 카드·칩·버튼을 얹습니다.
- 참고 그림의 공통점:
  - 3D 애니메이션 영화 같은 캐릭터
  - 흐릿하게 번진 카지노 홀(샹들리에, 보라·청록 네온 슬롯머신 보케)
  - 화면을 가로지르는 가죽 팔걸이와 초록 펠트
  - 앞쪽 칩이 흐릿한 피사계 심도
  - 테이블 너머로 몸을 기울인 캐릭터들

## 2. 화면과 기능

**① 로비 (기본 화면)**
- 현역 10명(로로 팀 5, 슈슈 팀 5)이 테이블 뒤에 섭니다.
- 각 캐릭터 앞 펠트에 그날 카드 2장(한국 ♦, 미국 ♣)을 **뒷면으로** 놓습니다.
- 각 자리에 애칭과 이번 주 점수를 표시합니다(없으면 "채점 전").
- 선두·꼴등 표시와 팀 구분(로로 팀 주황·갈색, 슈슈 팀 파랑)을 넣습니다.
- 다음 라운드 마감까지 남은 시간을 보여 줍니다.
- 메뉴 버튼: 진행, 기록판, 종목, 규칙(누르면 창으로 엶).

**② 클로즈업 (캐릭터나 카드를 누르면)**
- 그 캐릭터를 크게 보여 주고 배경은 더 흐리게 합니다.
- **카드 쪼이기:** 바카라처럼 카드를 아래부터 젖혀 공개합니다.
  - 위로 끌면 끈 만큼 젖혀지고, 한 번 누르면 천천히(조금 젖혔다 멈칫한 뒤 끝까지) 열립니다.
  - "모두 공개" 버튼을 둡니다.
- 앞면에는 시장(KR ♦ / US ♣), 종목명, 점수(%)를 표시합니다.
- 다 젖히면 캐릭터 말풍선에 **한 줄 이유**(`picks[].line`)를 타자 치듯 보여 줍니다.
- 닫기는 ×, 바깥 누르기, Esc 키입니다.

**③ 화면 방향**
- 휴대폰 **가로**(844×390)가 기본입니다. 한 화면에 들어가고 스크롤이 없어야 합니다.
- 휴대폰 **세로**(390×844)에서는 "가로로 돌려 주세요" 안내와 "세로로 볼게요" 선택을 둡니다. 세로 배치도 동작해야 합니다.
- 컴퓨터 화면(1280×720 이상)에서도 깨지지 않아야 합니다.

## 3. 데이터

- 공유 결과 파일 `league/public/results.json`(형식: `docs/results-bundle.md`)만 씁니다.
  - 캐릭터: `agents[]`의 `avatar`, `nickname`, `label`, `team`, `status`(현역만 테이블에)
  - 카드: `picks[]`의 `market`, `name`, `ticker`, `score`, `status`, `line`(가장 최근 라운드)
  - 순위·점수: `standings`, `team_weeks`
  - 마감·휴장: `calendar`
- 점수는 `status`가 `final`일 때만 확정으로 보여 줍니다. `provisional`은 "잠정", `pending`·`held`는 "채점 전/보류"입니다.

## 4. 캐릭터 그림

- 3D 캐릭터 14명 요청(2026-11-06-3d-characters.md)의 결과를 씁니다.
  - 시안 2장(뚝심이·알짜)은 받아서 테이블에 넣어 봤습니다. 흰 배경은 지워서 씁니다.
  - 카드 좌우는 **보는 사람 기준 왼쪽 ♦, 오른쪽 ♣**로 맞춰 주세요(시안은 반대였음).
- 아직 없는 캐릭터는 지금 2D 그림(`league/agents/avatars/characters.html`의 `#av-<이름>`)으로 대신해도 됩니다.
- 배경·칩·테이블 같은 그림은 이미지 생성으로 만들어도 되고, 코드(CSS/SVG/WebGL)로 그려도 됩니다. 생성 그림을 쓰면 그 도구의 약관이 지인 공개 화면에 쓰는 것을 허용하는지 확인해 주세요.

## 5. 꼭 지킬 것 (리그 규칙)

- **원 가격(주가·종가) 표시 금지.** 점수(%)만 씁니다.
- **마감 전 종목 표시 금지.** `results.json`에는 이미 마감이 지난 종목만 들어 있습니다. 다른 경로로 종목을 가져오지 않습니다.
- 화면에 출처 **"한국 시세: 한국거래소 통계정보"**를 꼭 표시합니다. 규칙 창에는 "미국 종가·배당 — Alpha Vantage"도 넣습니다.
- "모의 예측 게임 · 돈·베팅 없음" 안내를 넣습니다. 베팅·충전·보상처럼 보이는 요소(코인 잔액, 베팅 버튼, 상점)는 넣지 않습니다.
- 캐릭터는 창작 캐릭터이며 실존 인물을 닮지 않아야 합니다. 회사 로고 이미지는 쓰지 않습니다(이니셜 배지 등으로 대신).
- 외부 서버 없이 **정적 파일만으로** 동작해야 합니다. 외부 스크립트·글꼴은 버전을 고정한 공개 CDN만 씁니다(예: Google Fonts, jsDelivr).

## 6. 보내 줄 것

1. 폴더 하나: `index.html` + 그림·스크립트 파일. 데이터는 `data/table.js`(`window.TABLE = <results.json 내용>;`)에서 읽게 해 주세요. 그러면 운영자가 같은 데이터로 두 결과를 비교할 수 있습니다.
2. 캡처 4장: 가로 로비, 가로 클로즈업(카드 반쯤 젖힌 순간), 가로 클로즈업(다 연 뒤 말풍선), 세로 화면.
3. 폴더 전체 용량(그림 포함 5MB 이하 권장)과 사용한 외부 리소스 목록.

운영자에게 압축 파일로 전달해 주세요. 운영자가 저장소 `league/play-candidates/shushu/`에 올립니다.

## 7. 비교 기준

운영자가 두 결과를 같은 데이터, 같은 휴대폰 크기로 보고 고릅니다.

| 기준 | 보는 것 |
|---|---|
| 게임 느낌 | 참고 그림처럼 3D 카지노 게임 같은가 (PPT 같지 않은가) |
| 읽기 쉬움 | 휴대폰 가로에서 애칭·점수·카드가 바로 읽히는가 |
| 쪼이기 손맛 | 끌기·누르기가 자연스럽고 긴장감이 있는가 |
| 가벼움 | 휴대폰에서 빨리 뜨고 버벅이지 않는가 |
| 규칙 준수 | 5장을 모두 지켰는가 (하나라도 어기면 채택하지 않음) |

## 바뀌지 않은 것

- 제출 방법, 마감, 규칙(v1.8), `results.json` 형식은 그대로입니다.
- 지금 쓰는 화면은 새 화면이 채택될 때까지 그대로 둡니다.
