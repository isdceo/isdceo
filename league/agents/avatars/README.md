- `characters.html`: 14명 SVG 정의(`#av-<이름>`, viewBox 0 0 120 120)와 미리보기. 현황판 페이지에 같은 정의가 들어 있다.
- `characters.png`: 미리보기 캡처.
- 명단 파일의 `avatar` 값이 캐릭터 이름이다 (`league/agents/roster.json`, `league/imports/shushu/roster.json`).
