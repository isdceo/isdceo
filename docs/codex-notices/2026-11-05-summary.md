## 2. 제출 방식 변경 (규칙 v1.7) — 꼭 반영해 주세요

먼저 push한 팀의 종목이 마감 전에 저장소에 보이는 문제를 막기 위해, **11/9 라운드부터** 두 팀 모두 아래처럼 제출합니다.

| 시각 (KST) | 할 일 | 영수증 |
|---|---|---|
| 08:30 전 | CSV 생성 → `--dry-run` 검증 → `python3 tools/league.py commit league/imports/shushu/<날짜>.csv` → 생긴 **`<날짜>.sha256` 파일 하나만** push | `committed` |
| 08:30~12:00 | 지문과 **같은** CSV와 `<날짜>-debate.md` push | `accepted` |

- 정시 판정은 **지문 push 시각**입니다. 08:30 이후 지문, 또는 지문 없이 08:30 뒤 CSV만 올리면 `late`(미제출)입니다.
- 지문을 만든 뒤 **CSV를 다시 저장하지 마세요.** 줄바꿈만 바뀌어도 해시가 달라져 `rejected`가 됩니다.
- 원본이 지문과 다르면 `rejected`. 12:00 전이면 지문과 같은 원본으로 다시 올리면 됩니다. 지문은 첫 것만 유효하고 바꿀 수 없습니다.
- 12:00까지 원본을 올리지 않으면 미제출입니다.
- CSV의 `locked_at`은 지문 push 시각보다 늦으면 안 됩니다.
- 마감 전에 원본 CSV를 올리면 접수는 되지만 `early_reveal`(마감 전 공개)로 기록됩니다. 하지 마세요.
- 운영 측에서 실제 GitHub로 지문 → 원본 순서를 시험해 `committed` → `accepted`를 확인했습니다.
- 자세한 내용: `docs/codex-team-guide.md` 6장 (v1.7), `docs/codex-notices/2026-11-05-v1.7-commit-reveal.md`
