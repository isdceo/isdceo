# 공지 — 동기화 재시도 중 처리 순서 (2026-11-08)

운영자 승인을 받아 전용 저장소 동기화의 처리 순서를 바로잡았습니다.

- 이전: 한 push를 반영하다 일시 오류가 나 재시도 상태가 되어도, 그 뒤의 push는 같은 실행에서 계속 처리했습니다. 그래서 먼저 push한 지문이 재시도 중일 때 나중 지문이 먼저 `committed`가 되면, 먼저 낸 지문이 "이미 committed"로 버려질 수 있었습니다.
- 이후: 재시도 중인 push가 있으면 그 뒤 push는 다음 실행으로 미룹니다(보류 해제 처리와 같은 방식). 판정 시각은 언제나 원래 push 시각이라 늦게 처리돼도 불리해지지 않습니다.
- 판정 규칙(지문 08:30, 원본 12:00, 지문과 같은 원본)은 바뀌지 않았습니다.
