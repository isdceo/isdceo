# 규칙 v1.5 공지와 Claude 팀 연습 결과 — 슈슈 팀(Codex)

첨부한 codex-team-guide.md(v1.5)로 갱신했습니다. 두 팀에 똑같이 적용됩니다.

## 1. 공통 자료에 DART 공시 추가
- 06:50 공통 자료(가격 제외판)에 **대상 한국 종목의 최근 14일 DART 공시**가 들어갑니다.
  - 분류: 실적, 배당, 분할·병합, IR 개최 안내, 자사주, 주요사항
  - 형식: 제목·접수일·링크만
- 실적 발표·IR 일정 같은 이벤트는 먼저 이 공시 목록으로 확인해 주세요. 기사에만 있고 공시로 확인되지 않으면 "공시 미확인"으로 표시합니다.
  - 예: KT&G는 10/23에 "기업설명회(IR)개최(안내공시)"가 있습니다. Claude 팀 연습에서는 한 에이전트만 기사로 이 일정을 찾았는데, 실전에서는 두 팀 모두 같은 공시를 보게 됩니다.
- 채점의 한국 배당·분할 확인도 DART 공시(배당결정의 기준일→배당락일)로 합니다. 해석하지 못하면 0점이 아니라 보류입니다.

## 2. 출처 기록 기준 명확화
- **기준일을 확인하지 못한 출처는 "확인 못함"**으로 씁니다. 받은 날짜로 채우지 않습니다. 월까지만 알면 "2026-10"처럼 아는 만큼만 씁니다.
- **확보 시각은 출처마다 따로 재지 않아도 됩니다.** 여러 자료를 받은 직후 실제로 잰 시각 하나를 공통으로 적어도 됩니다(상한값). 받기 전 시각이나 추정 시각은 쓰지 않습니다.

## 3. 연습 경로를 팀별로 분리
- 슈슈 팀 연습은 `league/imports/sandbox-shushu/<날짜>.csv`로 해 주세요(Claude 팀은 `sandbox-claude`).
- 기존 `league/imports/sandbox/`는 영수증 시험에 이미 쓰여서, 같은 날짜로 내면 "이미 접수됨"으로 거부될 수 있습니다.

## 4. 참고: Claude 팀 연습 라운드 결과 (2026-11-05 라운드, sandbox)
- 절차: 독립 분석 → 반론 1회 → 확정 → CSV push. 영수증 `accepted`(10건)
- 실제 소요: 약 11분 (분석 4분, 반론 2분, 확정·push 2분)
- 같은 종목 쏠림: 5명 중 3명이 같은 한국 종목을 골랐습니다(규칙상 허용, 그대로 제출).
- 연습 추천은 11/5 종가가 나온 뒤(11/6 오전) 실제 데이터로 채점해 수집·채점 흐름을 점검합니다. 결과는 공유하겠습니다.
- 마감 전 상대 팀 당일 파일 열람 금지 규칙에 따라, Claude 팀의 종목은 이 공지에 적지 않았습니다. 연습 파일은 11/5 08:30 이후 열람해도 됩니다.
