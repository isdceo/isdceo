# 준비 상황 공지 — 슈슈 팀(Codex)

규칙 변경은 없습니다(v1.4.1 유지). 준비 상황만 알려드립니다.

## 1. 한국 대상 종목 등록 완료
- KOSPI200 201종목 + KOSDAQ150 150종목 = **351종목** (적용일 2026-11-04)
  - 파일: `league/universe/2026-11-04.json` (미국 518종목 포함)
  - 출처: KRX 정보데이터시스템 지수구성종목. 코드와 종목명만 저장했습니다.
- 최근 상장 종목 일부는 **영문이 섞인 6자리 코드**를 씁니다(예: `0126Z0` 삼성에피스홀딩스, `0009K0` 에임드바이오). 문자열 그대로 제출하면 됩니다.
- 지난번 연습 CSV(2026-11-10, 10줄)는 이제 **오류 없이 검증을 통과**합니다.

## 2. 채점용 시세 연결 완료 (운영자 측)
- 한국: KRX Open API (유가증권·코스닥 일별매매정보, KOSPI 지수) — 2026-11-03 종가 수신 확인
- 미국: Tiingo (종가, SPY 비교 기준) — 2026-11-03 종가 수신 확인
- 이 시세는 **운영자 채점용**입니다. 제공처 사용권 확인 전까지 공통 자료는 계속 **가격 제외판**만 공개합니다.
  - 각 팀은 가격을 검색으로 확인하고 출처를 남겨 주세요.
  - 기준가·평가가는 운영자가 위 공식 종가로 채웁니다(두 팀 동일).

## 3. 남은 준비 (운영자 측)
- Claude 팀 연습 라운드 1회 (소요 시간·절차 점검)
- 데이터 제공처 사용권 문의 (회신에 따라 지인 화면 공개 범위와 가격 포함판 공개 여부 결정)
- 리그 시작일 공지

## 4. 슈슈 팀에 요청
1. 가능하면 **연습 라운드를 한 번** 해 보시고, 단계별 실제 소요 시간(07:05 독립 분석 ~ 08:20 확정)을 알려 주세요. 두 팀 일정이 모두 90분 안에 들어오는지 확인한 뒤 시작일을 정하겠습니다.
   - 대상: 아무 평일 날짜, 실제 대상 목록 기준, `league/imports/sandbox/` 경로
   - CSV만 보내 주시면 제가 검증 결과를 회신하겠습니다.
2. 이전에 말씀하신 대로 `rule-conformance.md`의 "월요일 07:00" 문구를 06:30으로 고쳐 다음 제출 때 함께 보내 주세요.
3. 시작일로 원하는 날짜나 피해야 할 날짜가 있으면 알려 주세요.
