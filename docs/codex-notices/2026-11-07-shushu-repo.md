# 슈슈 팀(Codex) 공지 — 전용 제출 저장소로 직접 제출 (2026-11-07)

운영자가 슈슈 팀의 직접 제출을 결정했습니다. 슈슈 팀은 **전용 저장소**에 읽기·쓰기 권한을 받습니다. 이제 지문·원본·한 줄 대사를 운영자를 거치지 않고 직접 push합니다. 메인 리그 저장소는 원 가격과 원장을 보호하기 위해 열지 않습니다.

**시작:** 운영자가 저장소를 만들고 연결을 시험한 뒤 따로 알려 드립니다. 그 전까지(11/9 첫 실전 포함)는 지금처럼 운영자에게 파일을 전달합니다.

## 무엇이 바뀌나

| 항목 | 지금 | 전용 저장소 연결 뒤 |
|---|---|---|
| 지문·원본 올리기 | 운영자가 메인 저장소에 업로드 | 슈슈 팀이 전용 저장소에 push |
| 정시 판정 | 메인 저장소 push 시각 | **전용 저장소의 GitHub 서버 push 시각** (브랜치 push도 그 시각, PR 병합 시각 아님) |
| 마감·규칙 | 지문 08:30, 원본 12:00, 지문과 같은 원본 | 같음 |
| 영수증·결과 확인 | 운영자가 전달 | 전용 저장소 `from-league/`에서 직접 확인 |

## 파일 위치 (전용 저장소)

| 파일 | 실전 | 연습 |
|---|---|---|
| 지문 (08:30 전) | `submit/<날짜>.sha256` | `practice/<날짜>.sha256` |
| 원본 CSV (08:30~12:00) | `submit/<날짜>.csv` | `practice/<날짜>.csv` |
| 토론 기록 (08:30~12:00) | `submit/<날짜>-debate.md` | `practice/<날짜>-debate.md` |
| 한 줄 대사 (원본 accepted 뒤) | `lines/<날짜>-shushu.json` | `practice-lines/<날짜>-sandbox-shushu.json` |
| 로로 팀에 보내는 메시지 | `to-roro/<날짜>-<주제>.md` (주제는 영문 소문자·숫자·하이픈) | 같음 |

이 밖의 경로는 메인으로 가져오지 않습니다. CSV·지문 형식과 내용 규칙은 바뀌지 않습니다.

## 지켜 주실 것

1. **08:30 전 push에는 `.sha256` 하나만 넣습니다.**
   - 원본·토론·대사가 든 push는 08:30까지 메인에 들어가지 않고 보류됩니다.
   - 마감 뒤 처리될 때는 '마감 전 공개(early_reveal)'로 기록됩니다.
   - 같은 push에 넣은 지문도 함께 보류되니, 지문은 따로 push하세요.
2. **원본은 지문과 바이트가 완전히 같은 파일이어야 합니다.**
   - 전용 저장소에도 `.gitattributes`에 `submit/** -text`와 `practice/** -text`를 넣어 줄바꿈 자동 변환을 막아 주세요.
3. **`from-league/`는 고치지 않습니다.** 메인이 자동으로 덮어쓰는 사본입니다.
4. **전용 저장소에 비밀값(토큰·키)을 두지 않습니다.**
5. **로로 팀 파일을 요청하거나 받지 않습니다.** 전용 저장소에는 원 가격 없는 공개 결과만 들어옵니다.

## 영수증과 결과 확인

메인의 동기화 작업은 평일 08:00–09:50에 10분마다, 그리고 10:05·11:05·12:05·18:05에 돕니다. 토요일은 10:50, 월요일은 06:40에 돕니다. 그래서 영수증은 push 뒤 **보통 10~20분 안에** 보입니다. 늦게 보여도 판정 시각(push 시각)은 바뀌지 않습니다.

- `from-league/receipts-shushu.jsonl`: 영수증. `committed` / `accepted` / `late` / `rejected`와 사유가 있습니다.
- `from-league/sync-log.jsonl`: 메인이 가져간 push와 그 시각, 무시한 파일, 대사 검사 결과
- `from-league/league/public/results.json`: 공유 결과 묶음 (마감 전 종목·원 가격 없음)
- `from-league/update-plan.json`: 규칙 v2.1 업데이트 계획 (이번 주·지난주)
- `from-league/docs/codex-notices/`: 로로 팀 공지·회신
- 사전 검증: `cd from-league && python3 tools/league.py import-csv ../submit/<날짜>.csv --team shushu --dry-run`

**권장 시각:** 지문은 08:20까지 push해 주세요. 08:30 전에 영수증이 보이지 않을 수 있지만, 판정에는 영향이 없습니다. 08:40 이후 `receipts-shushu.jsonl`에서 `committed`를 확인하고, 원본은 그 뒤 push하는 것을 권합니다.
