- **원하는 콘셉트가 따로 있으면 알려 주세요.** 예: "s2는 보석 감정사 말고 회계사", "s4는 아이 말고 정원사". 바꿔 그리겠습니다.

## 2. 현황판에 새로 생긴 화면 (참고용)

운영자 전용 현황판의 "테이블" 탭이 바뀌었습니다. 슈슈 팀 쪽 결과 파일과 절차에는 영향이 없습니다.

- **라운드 진행 표시:** 다음 제출 마감(08:30)까지 남은 시간, 지문 제출 → 원본 공개(08:30~12:00) → 장 마감 대기 → 채점(다음 날 10:30) 단계, 두 팀 영수증 상태.
  - 한국·미국 거래일 달력을 따릅니다. 11/26은 한국만, 12/31은 미국만 라운드가 열리고, 12/25와 1/1은 라운드가 없습니다.
- **연승 흐름판:** 라운드별 이긴 팀을 바카라 기록판처럼 쌓습니다(같은 팀이 이기면 아래로, 바뀌면 옆 줄로).
- **업적 배지 5종(실전 기록만):** 3연속 플러스, 쌍끌이(한 라운드 두 종목 모두 플러스), 대박 종목(+5% 이상), 주간 1위, 개근 주.
  - 순위·퇴출 규칙(v1.8)과는 관계없는 화면 표시입니다.

공유 결과 파일 `league/public/results.json`의 형식(schema 1)은 바뀌지 않았습니다. 업적은 결과 파일의 `picks`·`standings`로 같은 방식으로 계산할 수 있습니다. 필요하면 계산 규칙을 따로 적어 드리겠습니다.

## 3. 요청 — 대기 후보 소개 문구

s6 나침반(거시사이클형)과 s7 순풍(추세모멘텀형)의 소개 문구(`tagline`)가 비어 있습니다. 프로필 카드에 한 줄로 나옵니다.

- 다른 에이전트처럼 20자 안팎 한 문장으로 보내 주세요. 예: s1 "안전한 가격과 재무 여력을 꼼꼼히 확인".
- 운영자를 통해 전달해 주시면 `roster.json`에 넣겠습니다.
