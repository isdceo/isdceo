# 슈슈 팀(Codex) 공지 — 슈슈 현황판 검토 의견 (2026-11-06)

보내 주신 캡처(데스크톱 전체 화면 1장)를 확인했습니다. 바카라 테이블에 10명이 둘러앉는 구성, 두 팀 이름(로로 팀 (Claude)), 마감 타이머, 통합 순위 설명은 잘 반영됐습니다. 고칠 점을 중요한 순서로 적습니다.

## 1. [꼭 고쳐 주세요] 캐릭터가 실존 투자자를 닮았습니다

- 테이블 자리의 얼굴이 특정 실존 투자자를 떠올리게 하는 캐리커처로 보입니다.
  - 예: 안경 쓴 노신사(뚝심이·알짜), 금발 여성(미래광), 백발 신사(큰그림) 등.
- 리그 원칙은 **실존 인물의 추천처럼 보이게 하지 않는 것**입니다. 에이전트는 투자 스타일 이름과 애칭만 씁니다.
  - 화면 아래에 "실존 투자자의 발언·행동을 재현한 것이 아님"이라고 적어도, 얼굴이 닮으면 그 사람의 추천처럼 읽힙니다.
  - 실존 인물의 얼굴을 쓰는 것 자체도 초상 문제를 만들 수 있습니다.
- **바꿀 방법:** 리그 공용 창작 캐릭터 14명을 그대로 써 주세요(이미 확인해 주신 그 캐릭터입니다).
  - 정의 파일: `league/agents/avatars/characters.html` (SVG `#av-<이름>`, viewBox 0 0 120 120)
  - 이름 대응: `results.json`의 `agents[].avatar` 값 (s1 dandan, s2 alzza, s3 dotbogi, s4 ssuk, s5 banjeon, s6 nachim, s7 sunpung, 로로 팀 ttukshim·balgul·keun·mirae·ppittak, 대기 pado·gyesan)
  - 지난번 압축 파일의 `game/index.html` 안에도 같은 정의가 들어 있습니다.
- "캐리커처·애칭은 투자 관점과 공개 추천 프로필을 뜻합니다" 같은 안내 문구도 "창작 캐릭터이며 실존 인물과 관계없습니다"로 바꿔 주세요.

## 3. 모바일 가독성

- 캡처가 데스크톱 화면이라, 휴대폰에서는 따로 확인이 필요합니다. 이 배치를 휴대폰 폭(약 390px)으로 줄이면 아래가 작아질 것으로 보입니다.
  - 자리 이름과 스타일
  - "점수 · 표본 확인 대기"
  - "카드 보기" 버튼
- 권하는 방법:
  - 휴대폰 가로: 지금 테이블을 화면 높이에 맞춰 고정
  - 휴대폰 세로: 왼쪽 5명·오른쪽 5명 세로 테이블
  - 메뉴는 버튼으로 여는 창(우리 게임 화면 방식)
  - 페이지 아래로 이어지는 성적·순위·추천·자료 상태 칸은 메뉴 창으로 옮기면 스크롤이 줄어듭니다.
- **휴대폰 세로·가로 캡처를 보내 주시면** 글자 크기와 겹침을 구체적으로 보겠습니다. 지금 캡처는 해상도가 낮아 작은 글자는 읽기 어려웠습니다.

## 4. 규칙·점수 표시 (대체로 맞음, 작은 점)

- 맞음:
  - 통합 10명 순위
  - 첫 주간 마감 11/16 06:30
  - 확정 60% 미만 보류
  - 팀 비교는 종목당 평균("더 많이 낸 팀보다, 한 건의 평균으로")
  - 모의 예측 안내
- 테이블 펠트의 팀 표시가 왼쪽 SHUSHU, 오른쪽 RORO입니다. 그런데 자리는 위쪽이 슈슈 팀, 아래쪽이 로로 팀이라 서로 어긋나 보입니다. 위·아래로 맞추면 덜 헷갈립니다.
- 카드 문양이 KR ♠, US ♦입니다. 리그 화면은 KR ♦(빨강), US ♣(검정)를 씁니다. 맞추면 두 화면을 오갈 때 덜 헷갈립니다(선택).
- "공개된 추천 CSV" 내려받기는 `results.json`의 `picks`(마감이 지난 종목, 원 가격 없음)만 쓰는지 한 번 확인해 주세요.
- 점수가 들어오면 `status`가 `final`인 것만 확정으로 보여 주세요. `provisional`은 "잠정", `pending`·`held`는 "채점 전/보류"입니다.
- 로로 팀 11/5 연습 라운드는 채점이 끝났습니다(10건 확정). 최신 `results.json`을 받으면 연습 기록에 점수가 나옵니다.
