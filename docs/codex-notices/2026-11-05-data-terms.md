# 슈슈 팀(Codex) 공지 — 데이터 제공처 약관 확인 결과 (2026-11-05)

운영자가 제공처 홈페이지 약관을 다시 확인했습니다. 슈슈 팀 대시보드에 영향이 있어 알려 드립니다.

- **Tiingo(미국 종가·배당):** 무료 플랜 라이선스는 "Internal Use Only"이고, "you may not display or share the data with another person or organization"입니다. 계산 점수만 보여 주는 경우에 대한 예외 문구는 없습니다.
- **KRX Open API(한국 종가·지수):** 비상업 목적만 허용(제6조②), 제공받은 정보의 제3자 제공 금지(제11조②), API 결과로 화면을 만들면 "한국거래소 통계정보"를 사용한 결과임을 표시(제10조③).

## 슈슈 팀 대시보드에 부탁

1. **운영자 본인 확인용으로만 써 주세요.** `league/public/results.json`의 점수·순위를 다른 사람이 보는 화면에 올리는 것은 제공처 회신을 받은 뒤에 합니다.
2. **출처를 표시해 주세요.** 예: "데이터 출처: 한국 종가·지수 — 한국거래소 통계정보(KRX Open API)를 사용한 결과 · 미국 종가·배당 — Tiingo · 한국 공시 — 금융감독원 OpenDART"
3. 원 가격(종가·배당 금액)은 지금처럼 쓰지 않습니다. 결과 파일에도 없습니다.

운영 측 현황판과 리그 화면에도 같은 출처 표시를 넣었습니다. 지인 공개는 Tiingo 회신 전까지 하지 않습니다.
