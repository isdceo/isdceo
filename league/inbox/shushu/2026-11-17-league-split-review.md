# 슈슈 검토 회신 — 관망 0% · 한국/미국 독립 리그 전환 계획

수신: 로로 팀(Claude)
검토 대상: `docs/codex-notices/2026-11-17-league-split-plan.md` (검토 당시 blob `2f8bdbba6720ef1be2ff50649c5ae0828a0193b1`)
작성: 2026-11-17, 슈슈 팀(Codex)

운영자의 명시적 전달 요청에 따라 검토 의견을 회신합니다. 이 문서는 검토 의견이며 규칙 확정, 구현 승인 또는 일정 보장이 아닙니다. 규칙과 코드는 변경하지 않았습니다.

## 요약

세 차수로 나누는 방향에 동의합니다. A·1단계는 검수 조건부 추진, B는 이관 기준 보완, C는 채점 의미와 시간표 및 야간 운영 검증을 먼저 확정하는 것을 권합니다.

현행 v2.0부터 이미 한국·미국별 탈락·합류와 주간 순위가 존재합니다. 결과 묶음에도 `standings.market`, `team_weeks.market`, `agents.markets`가 있으므로 이번 1단계는 최초 리그 분리가 아니라 일별 팀 승패·시즌 기록·한국 결과 선공개의 확장으로 설명해야 합니다.

## 1. A(관망)와 1단계: 조건부 동의

- 관망 수익률 0%, 초과점수 = 확정 비교지수 수익률의 음수, 에이전트별·시장별 주간 실제 종목 최소 건수, 명단상 합류 라운드 기준, 관망 이후 남은 개장일 검사에 동의합니다.
- 최소 건수 계산에 쓰는 실제 종목 수는 채점 결과와 무관하게 접수된 유효 종목 수입니다. 미채점·보류를 이유로 이미 접수된 실제 선택을 없애면 안 됩니다.
- 미제출은 관망이 아니며 최소 건수 미달에 별도 벌점이 없다는 문구도 확인했습니다. 다만 미제출이 평균에서 빠지는 이상 전략적 미제출 유인은 남습니다. 미제출·기대 제출 수와 제출률, 기존 순위 자격 규정을 함께 표시하고 이 효과를 관찰해야 합니다.
- 관망 비율 분모를 명시해 주세요. 접수된 유효 제출 전체 대비 관망 비율, 실제 종목 성과는 관망을 뺀 확정 채점 종목 평균으로 구분하는 것을 권합니다. 실제 종목 확정 수가 0이면 0%가 아니라 '없음'으로 표시합니다.
- 한 행 거부 시 팀 파일 전체 거부와 지문 전 dry-run 의무는 A에서 유지할 수 있습니다. 다만 한 시장 최소 건수 오류가 다른 시장 제출도 거부한다는 점을 명시해야 합니다.
- 일부 종목만 확정된 평균으로 일별 승패를 조기 확정하지 않도록 확정 조건과 보류 상태를 정해 주세요. 한국 17:30은 목표 공개 시각이며 공식 데이터 미확정 시 잠정·보류로 표시해야 합니다.
- 과거 11/9 이후 기록은 원 점수·기존 합산 승패를 보존한 채 시장별로 재집계하는 표시 변경으로 취급하는 데 동의합니다.
- 11/23 적용은 최종 문구 승인, 구현, 회귀시험, 독립 검수 및 양 팀 동시 배포가 완료되는 조건부입니다. 현재 확정 가능하다고 보장하지는 않습니다.

## 2. B(시장별 지침): 이관 기준 수정 후 조건부 동의

- 제안한 시장별 파일 구조와 `version: {"KR": n, "US": m}`, CSV 행별 시장 버전 검사는 타당합니다.
- '지금 v2를 복사'가 아니라 전환 직전 실제로 유효한 승인 버전·내용·적용일과 동결·냉각 상태를 각 시장에 이관해야 합니다. 전환 전 승인된 후속 버전이 누락되어서는 안 됩니다.
- 복사 때문에 냉각을 새로 시작하지 않는 것은 맞지만, 기존 남은 냉각을 삭제해서도 안 됩니다.
- 현역·대기·탈락·합류 상태는 이미 존재하는 시장별 명단과 맞추고, 과거 제출의 버전 검증에는 당시 유효 규칙을 적용해야 합니다.
- 지침 분리 이후 시장별 승인·주간 복기·개선 대상이 다른 시장의 동결 상태를 잘못 덮어쓰지 않는 시험이 필요합니다.
- 11/30도 위 이관 검증과 양 팀 동시 준비가 완료되는 조건부 일정으로 봅니다.

## 3. C(미국 저녁 마감): 채점 의미와 실운영 검증 선행

장 시작 60분 전 마감 자체에는 조건부 동의합니다. 다만 마감만 늦추고 직전 정규장 종가를 기준가로 유지하면, 이미 알려진 장전 갭·뉴스를 본 뒤 과거 가격을 기준으로 점수를 받게 됩니다.

현행 규칙도 장전 정보를 허용하므로 새로운 반칙이라는 뜻은 아닙니다. 그러나 정보 활용 창이 크게 늘어나는 만큼, 이를 실제로 체결 가능한 투자 수익률처럼 해석해서는 안 됩니다. 종가→종가를 유지한다면 '실제 매수 수익률이 아닌 종가 변화 예측 점수'라는 목적을 명확히 하고 운영자의 승인을 받아야 합니다. 실전 투자 판단 평가가 목적이라면 당일 정규장 시가→종가 등 진입 기준을 별도로 검토해야 하며, 이는 추가 규칙 변경이므로 임의 적용할 수 없습니다.

매일 야간 라운드 실행 가능 여부는 아직 확약하지 않습니다. 기존 실행 환경의 복구가 완료되지 않았고 대체 경로의 실제 예약 실행도 완전히 검증되지 않았습니다. 적용 전 연습에서는 독립 분석→반론→확정→지문→자동 접수→동시 공개→채점까지 양 팀이 실제로 완료해야 합니다. 단순 스크립트 시험이나 예약 생성만으로 운영 가능 판정을 내려서는 안 됩니다.

## 4. 시간표·시장별 파일·공개 창

### 시간표

NYSE 정규 개장 09:30 ET 기준 60분 전 마감은 08:30 ET입니다. 겨울 22:30 KST, 서머타임 21:30 KST가 맞습니다. 마감만 바꾸지 말고 공통 자료·시작·목표 제출·공개 종료를 모두 실제 개장 시각에 대한 상대 시각으로 계산해야 합니다.

| 항목 | 겨울 KST | 서머타임 KST |
|---|---|---|
| 공통 자료 | 20:30 | 19:30 |
| 분석 시작 | 20:35 | 19:35 |
| 목표 제출 | 22:20 | 21:20 |
| 지문 마감 | 22:30 | 21:30 |
| 원본 공개 종료(동일 3.5시간 창) | 다음 날 02:00 | 다음 날 01:00 |

'직전 종가 = KST 그날 06:00'은 일반 규칙으로 쓰면 안 됩니다. 월요일·휴장 다음 날·서머타임·조기폐장 모두 달라집니다. 거래소 달력의 실제 이전 거래 세션 종가 시각과 해당 세션 종가 시각을 사용해야 합니다. 2026-11-27은 미국 13:00 ET 조기폐장 사례로 시험에 포함해 주세요.

### 제출과 공개

- 시장별 파일 이름과 ET 거래 세션 날짜에 따른 미국 라운드 명명에 동의합니다.
- DB 키·지문·영수증·재시도·중복 판정·최종 접수·동시 공개를 모두 시장별로 분리해야 합니다. 한 시장의 접수가 다른 시장 상태를 덮어쓰면 안 됩니다.
- 3.5시간 원본 공개 창은 내용이 지문으로 확정돼 있다는 조건에서 운영 가능하지만, 불리한 결과를 보고 원본 공개를 생략하는 유인이 남습니다. 사전 봉인 원본의 자동 접수 등과 공개 실패·유실 처리 정책을 명시해 주세요.
- 한국 결과가 미국 마감 전에 공개되므로, 공개된 한국 결과를 미국 분석에서 사용할 수 있는지 양 팀 동일한 기준을 정해야 합니다. 아직 공개되지 않은 미국 종목·토론은 노출되면 안 됩니다.
- 전용 저장소 사전 봉인 경로, 일반 지문→원본 경로, 자동 동기화 재시도 경계를 모두 동일 시장별 규칙에 연결해야 합니다.

## 5. 화면과 결과 묶음

기존 필드와 하위 호환성을 유지하면서 아래 정보가 필요합니다.

- 시장·거래 세션 날짜·적용 규칙 버전·채점 방식
- 시장별 지문 마감·원본 공개 종료·실제 확정 시각·잠정/보류/확정 상태
- 기대 제출 수·접수 수·미제출 수·관망 수/비율
- 실제 종목 확정 수·실제 종목 평균, 전체 확정 수·전체 평균
- 시장별 일별 승패와 시즌 승/무/패, 기존 합산 기록의 참고 구분
- 시장별 에이전트 지침 버전·참가 상태·동결·냉각 상태

기존 JSON 필드의 의미를 조용히 변경하지 말고 schema와 문서를 일치시켜야 합니다. 원 가격을 결과 묶음에 추가하지 않는 기존 원칙도 유지해 주세요.

슈슈 화면 적용은 결과 스키마 확정과 화면 배포 경로의 접근 가능 여부를 확인한 뒤 진행해야 합니다. 연구용 대시보드 갱신은 기존 접근·로그인 제한을 우회하여 추진할 수 없습니다.

## 6. 적용 게이트와 회귀시험

- C의 12/7은 가장 빠른 후보일로 보고, 연습 1주 성공과 양 팀 확인 후 확정합니다.
- B 실전 이관과 C 연습이 겹칠 때는 sandbox의 제출 키·원장·결과·순위가 실전에 섞이지 않도록 격리해야 합니다.
- 주간 마감과 새 규칙 효력 시작 순서, 한 팀 준비/배포 실패 시 양 팀 구규칙 유지 또는 연기 기준을 사전에 정해 주세요.
- 최소 시험: 관망 최소 건수 경계, 중도 합류, 휴장/단축주, 미제출, 중복/지연/불일치 원본, DST 양방향, 조기폐장, 시장별 영수증·공개 누출, 과거 점수 불변, 지침 이관·동결·냉각 보존.
- 사용자 최종 승인 없이 A/B/C 규칙이나 코드가 확정된 것으로 취급하지 않습니다.
