# 슈슈 팀 초기 참가 파일

이 압축파일의 league/ 디렉터리를 대상 저장소 루트에 복사한다. roster.json과 agents/s1–s5/v1.md만 초기 참가 제출용이다. 자동 push, 예약 실행, 실제 추천·가격, 상대팀 분석은 포함하지 않는다.

## 준비 상태
- 초기 명단 5명과 v1 지침 작성, JSON 및 파일 대응 관계 검증 완료.
- 실제 저장소 규칙·채점 엔진·universe·snapshot은 아직 읽지 못했으므로 저장소 dry-run 통과를 주장하지 않는다.
- 리그 시작일, 실제 시세, 공통 snapshot, 전체 universe 준비 후 시작한다.
- 각 지침의 운영 적용 여부는 사용자/운영자 확인이 필요하다.

## 운영자에게 확인할 항목
1. 월요일 07:00 순위 집계 후 탈락자를 알 수 있는데 같은 시각 이전에 대체자를 등록하라는 규칙은 순서 충돌이다. '07:00 집계 → 07:05 이전 교체 → 독립 분석' 또는 사전 대체후보 승인 중 하나를 확정해야 한다.
2. GitHub push payload의 repository.pushed_at이 실제 수신 시각으로 어떤 타입·값을 주는지 실행 테스트해야 한다. workflow 생성 시각과 push 수신 시각을 혼동하지 않는다. 이벤트 ID·SHA·CSV 해시를 보존하고 서버 근거가 없으면 accepted 판정을 만들지 않는다.
3. 미국 정규장 종가 16:00 ET는 조기 폐장일 예외가 있다. XNYS 달력의 실제 세션 종료를 적용한다. 한국도 특별 세션 시간은 달력 기준을 확인한다.
4. 08:30 이후 정보를 못 쓰는 규칙과 장 종료 뒤 선택 구조를 함께 적용한다. 스냅샷은 07:00에 제공하되 추가 웹 자료의 공개·접근 시각을 보존한다.
5. 미제출·장기 정지·상장폐지를 평균에서 제외하면 성과가 유리해지는 편향이 있다. 확정 평균과 함께 제출률·무효율을 반드시 공개하고 임의로 규칙을 변경하지 않는다.
6. 가격지수 대비 총수익률 차이는 배당 효과를 포함하므로 순수 알파라 표현하지 않는다. 공식 점수와 참고 지표를 구분한다.
7. 토요일 복기는 미국 금요일 채점이 아직 잠정일 수 있다. 잠정 상태를 명시하고 확정 후 보완 기록을 추가한다.
8. 무료 가격 데이터의 계산·지인 표시 권한과 AI 실행 예산은 여전히 확인 필요하다.

## 향후 제출
공통 자료와 시작일을 받은 후 실제 날짜 CSV를 작성한다. 예시 종목을 실제 추천으로 제출하지 않는다. 저장소의 tools/league.py --dry-run으로 검증하고 마감 이전 push 후 accepted 영수증을 확인한다.
