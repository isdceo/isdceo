# 규칙 v1.5 대조 및 문구 정정

제공된 연습 묶음의 `docs/codex-team-guide.md` 규칙 v1.5(2026-11-04)를 기준으로 기존 대조 문서를 정정했다. 이 문서는 규칙 대조 메모이며 운영 완료 보고가 아니다.

- 명단: 로컬 준비본과 제공된 연습 묶음의 `league/imports/shushu/roster.json`은 members 5명, bench s6·s7 순서다. 총 7개의 고유 id이며 모두 version=1이다. 파일 내용 확인과 운영자 승인·활성화 여부는 구분한다.
- 일일 절차: 규칙상 07:05 독립 분석 → 반론 1회 → 08:30 KST 이전 확정·push 순서다. 기존 분석 지침의 공개 투자 원칙 참고, KR/US별 기준·회피 유형 보강은 준비 문서 내용이며, 실제 절차를 수행했다는 뜻은 아니다.
- 출처: `URL|기준일[|확보시각]` 형식이다. 기준일을 모르면 `확인 못함`, 월까지만 알면 아는 범위만 쓴다. 확보시각은 선택 사항이지만 기록을 권장하며 `+09:00`을 포함한다. 여러 자료를 받은 직후 실제로 잰 공통 시각을 상한값으로 쓸 수 있다. 받기 전 시각·추정 시각은 쓰지 않으며, 확보시각이 마감 이후면 제출이 거부된다.
- 공통 자료: v1.5에는 DART 최근 14일 공시가 포함된다. 실적 발표·IR 일정은 공통 자료의 DART 공시에서 먼저 확인하고, 기사에만 있고 공시로 확인되지 않으면 `공시 미확인`으로 표시한다.
- 주간 집계와 교체: 월~금 라운드를 다음 주 **월요일 06:30 KST**에 집계·마감한다. 교체 조건이 충족되면 사전 승인된 대기 후보를 순서대로 투입하며, **같은 날 07:05 독립 분석부터** 참가한다. 최하위 확정 점수 6건 미만, 팀 전체 30건 미만 또는 최하위 완전 동점이면 교체를 보류한다. 쓸 수 있는 대기 후보가 없으면 자리를 비우고, 빈자리는 미제출로 세지 않는다. 승인 전 임의 활성화는 하지 않는다.
- 제출 인원: v1.5 체크리스트는 `활성 멤버 전원(빈자리가 있으면 활성 인원 기준)`이라고 명시한다. 기존의 ‘5명 모두’ 해석 확인 사항은 이 문구로 정리한다.
- 서버 시각 판정: v1.5 본문은 `repository.pushed_at`이 없을 때만 워크플로 생성 시각 `created_at`을 쓰고, 두 서버 시각이 모두 없으면 `accepted`로 판정하지 않는다고 명시한다. 기존의 ‘안내서 본문에 반복되지 않았다’는 문장은 더 이상 해당하지 않는다. 실제 push 처리와 영수증 발급은 별도 검증 대상이다.
- 복기: 토요일 복기에서 잠정 항목은 잠정으로 표시하고, 확정 후 보완 기록을 추가한다. 분석 지침 변경은 새 버전 파일을 만들고 사용자(운영자) 승인 후 다음 라운드부터 적용한다. CSV의 `agent_version`은 승인된 현재 버전과 같아야 한다.
- 연습 경로: v1.5의 슈슈 팀 경로는 `league/imports/sandbox-shushu/<날짜>.csv`다. 기존 준비본의 `league/imports/sandbox/2026-11-10.csv`는 예시 값으로 만든 형식 시험 파일이며, 이번 문서 정정으로 경로를 옮기거나 내용·달력·대상 종목 검증을 마친 것은 아니다. 새로 제공된 연습 묶음은 2026-11-06 라운드용이며, README에 따르면 공통 자료는 2026-11-04 16:21 KST에 미리 생성됐다. 이를 라운드 당일 최신 자료로 간주하지 않는다.
- 조기폐장: 해당 날짜의 `schedule` 출력과 거래소 달력의 실제 종료 시각을 기준으로 확인한다.

## 이번 수정 범위와 확인 상태

이번 수정은 이 대조 문서에만 적용했다. 에이전트 지침, 일일 절차서, CSV 또는 저장소 운영 설정까지 v1.5로 변경한 것은 아니다.

실전 제출·가격 채점·주간 탈락 집계를 이번 검토에서 실행하지 않았다. `accepted` 영수증 발급이나 자동화 활성화를 확인한 것도 아니다. 제공된 연습 묶음의 `league/config.json`에는 `automation_enabled: false`가 기록돼 있으며, 실제 저장소의 현재 운영 상태는 별도 확인이 필요하다.
