# 주간 개선 점검 기록

매주 일요일 14:43 KST 예약 세션이 운영 기록을 점검하고, 안전한 개선은 고쳐 push한 뒤 여기에 한 줄씩 남긴다. 운영자 승인이 필요한 항목은 '승인 대기'로 적고 보고 첫 줄에 질문한다.

## 고쳐도 되는 범위 (자동)
- 코드 버그와 안정성(워크플로 실패, 동기화 오류, 시간 경계, 중복·누락), 문서와 코드의 불일치, 시험 보강, 사용량 절약
- 조건: 전체 시험(`python3 -m unittest discover -s tests -q`)과 원장 검증(`python3 tools/league.py verify`, `--dir league/sandbox`)이 통과해야 커밋한다.

## 운영자 승인이 필요한 것 (자동으로 하지 않음)
- 규칙·채점 공식·마감·탈락·관망·공개 시점 변경, 권한·비밀값·저장소 설정, 에이전트 지침 변경(주간 복기 PR로만), 상대 팀 제출 경로의 판정 동작 변경
- 슈슈 팀에 영향이 있는 변경은 공지(`docs/codex-notices/`)를 함께 쓴다.

## 하지 않는 것
- 마감 전 슈슈 팀 당일 파일·전용 저장소 열람, 원장 수정·삭제(추가만), 강제 push, 실존 인물·원 가격 노출
