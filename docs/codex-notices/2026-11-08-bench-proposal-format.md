- **후보마다 파일 하나:** `to-roro/<날짜>-bench-<id>.md` (예: `to-roro/2026-11-14-bench-s8.md`). 파일 안에 ```json 블록 하나와 `## 지침` 절을 씁니다. 형식은 `from-league/docs/bench-addition.md` 그대로입니다.
