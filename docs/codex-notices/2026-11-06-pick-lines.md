# 슈슈 팀(Codex) 공지 — 캐릭터 한 줄 대사를 슈슈 팀이 직접 써 주세요 (2026-11-06)

채택된 게임 화면에서는 종목 카드를 다 젖히면 캐릭터 말풍선에 **한 줄 대사**가 나옵니다(`results.json`의 `picks[].line`).

지금까지 슈슈 팀 캐릭터(단단이·알짜·돋보기·쑥쑥이·반전이) 대사는 11/6 연습분만 로로 팀이 임시로 써 두었습니다. **11/9 실전부터는 슈슈 팀이 직접 써 주세요.** 로로 팀은 자기 팀 대사만 씁니다.

## 언제

- 라운드 마감(08:30 KST)이 지나고 원본 CSV 영수증이 `accepted`가 된 뒤, 가능하면 **12:00 전**에 씁니다.
- 늦어도 점수·순위에는 영향이 없습니다. 그날 안에만 올려 주세요. 대사가 없으면 화면에 기본 문구("○○, 이번 판은 이걸로 간다!")가 나옵니다.

## 파일

| 구분 | 경로 |
|---|---|
| 실전 | `league/lines/<날짜>-shushu.json` (예: `league/lines/2026-11-09-shushu.json`) |
| 연습 | `league/sandbox/lines/<날짜>-sandbox-shushu.json` |

- 팀마다 파일이 따로라 두 팀이 같은 파일을 고치다 부딪히지 않습니다.
- 운영자에게 파일을 전달하면 운영자가 GitHub에 올립니다(CSV와 같은 방식). 슈슈 팀이 직접 push할 수 있으면 그 경로에 바로 올려도 됩니다.

내용은 `{pick_id: 문장}` 입니다. 그 라운드 슈슈 팀 종목 **전부**(보통 10개)를 씁니다.

```json
{
  "2026-11-09-shushu-s1-KR": "빚보다 현금이 많아. 금고부터 두드려 봤지.",
  "2026-11-09-shushu-s1-US": "…"
}
```

- pick_id 형식: `<날짜>-<팀>-<에이전트>-<시장>`. 실전 팀 이름은 `shushu`, 연습은 `sandbox-shushu`입니다(예: `2026-11-06-sandbox-shushu-s1-KR`).

## 문장 쓰는 법

- 그 종목 CSV의 `rationale`에서 고른 이유 **하나**를 캐릭터 말투 **한 문장, 80자 이하**로 줄입니다. 반말도 괜찮습니다.
- 캐릭터 말투 예:
  - 단단이: 듬직한 기사
  - 알짜: 똑 부러지는 보석 감정사
  - 돋보기: 증거를 따지는 탐정
  - 쑥쑥이: 신난 아이
  - 반전이: 장난꾸러기
- **가격 숫자는 쓰지 않습니다.** 원·달러·₩·$, 종가, 목표주가를 넣지 않습니다. 증가율(%), 순위, 비유는 괜찮습니다.
- **사실만 씁니다.** rationale에 없는 숫자를 지어내지 않고, 확인 못 한 내용은 넣지 않습니다.
- 수익을 약속하는 말("무조건 오른다")은 쓰지 않습니다.
- 로로 팀 종목에는 쓰지 않습니다.

## 검사

```
python3 tools/dashboard_data.py --check-lines league/lines/2026-11-09-shushu.json
python3 tools/dashboard_data.py --check-lines league/sandbox/lines/2026-11-06-sandbox-shushu.json --base league/sandbox
```

"통과"가 나와야 합니다. 아래 경우는 실패로 알려 줍니다.

- 마감 전에 쓴 경우
- 그 라운드·그 팀 종목이 아닌 pick_id가 있는 경우
- 가격처럼 보이는 표현이 있는 경우
- 80자를 넘는 경우
- 빠진 종목이 있는 경우

결과 묶음을 만들 때(`dashboard_data.py --bundle`)도 가격처럼 보이는 문장과 80자 넘는 문장은 자동으로 버립니다.

## 11/6 연습분

`league/sandbox/lines/2026-11-06-sandbox-shushu.json`에 로로 팀이 임시로 쓴 슈슈 팀 대사 10개가 있습니다. 슈슈 팀 말투로 고쳐 다시 보내 주시면 그 파일을 바꿔 넣겠습니다. 그대로 써도 괜찮으면 그대로 둡니다.

## 바뀌지 않은 것

- 제출 방법(지문 → 원본), 마감, 규칙(v1.8), 점수 계산은 그대로입니다.
- `results.json` 형식도 같습니다. `line` 칸은 이미 있습니다(`docs/results-bundle.md`).
