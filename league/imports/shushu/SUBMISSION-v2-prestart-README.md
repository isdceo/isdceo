# 슈슈 팀 시작 전 보강 패키지

## 기준 및 준비 상태
사용자가 대화로 제공한 규칙 v1.3 원문(2026-11-04 표기)과 운영자 회신을 대조해 작성했다. roster는 본문의 members/bench 객체 형식을 따르며, 안내서 코드 블록의 이전 배열 예시는 사용하지 않았다. 저장소 엔진·universe·snapshot은 아직 직접 읽지 못했으므로 실전 제출 호환성은 운영자 검증을 기다린다. 이전 명단 등록은 운영자 회신 내용이며 저장소 상태를 직접 확인한 것은 아니다.

## 파일
- league/imports/shushu/roster.json: members 5명, bench 2명(순서 s6 거시사이클형, s7 추세모멘텀형). 대기 후보는 사전 승인 전 참가 불가.
- agents/s1–s7/v1.md: 기존 5명 세부 지표·회피 유형·KR/US 판단 보강 및 대기 후보 지침. 시작 전 보강이므로 version=1 유지.
- daily-procedure.md: 07:00–08:30 예상 절차와 시간.
- league/imports/sandbox/2026-11-10.csv: 10행 연습 전용. 실제 추천이 아니다. 모든 URL·시각은 명시적 예시이며 가격 없음. 실제 universe와 거래소 달력을 검증하지 않았다.

## 검증 범위
JSON 구문, members/bench 수·id 유일성, 지침 경로, CSV 헤더·10행·시장별 한 행·KR 6자리 문자열·+09:00·빈 필드 여부와 ZIP 무결성만 로컬 점검했다. 원본 tools/league.py를 실행하지 않았으므로 --dry-run 통과 또는 accepted를 주장하지 않는다. 운영자가 sandbox 엔진 검증 결과를 알려줘야 한다.

## 적용
저장소 루트에 경로를 맞춰 사용하되 관련 파일만 반영한다. 이 패키지는 GitHub에 업로드·push되지 않았다. 실전 CSV나 예약 실행은 없다. 이전 패키지 대신 이 패키지를 검토하고 실제 자료·시작일과 대기 후보 승인을 확인한다.
