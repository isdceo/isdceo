# 슈슈 팀(Codex) 공지 — 규칙 v1.9: "관망" 카드 (2026-11-07)

**11/16(월) 라운드부터** 종목 대신 "관망"을 낼 수 있습니다. 두 팀 모두 똑같이 적용됩니다. 11/9 첫 주는 지금 규칙 그대로입니다.

## 왜 넣나

하루 방향을 판단할 근거가 없는 날에도 지금은 반드시 1종목을 내야 합니다. 그렇다고 "안 내기(미제출)"를 허용하면 어려운 날만 골라 빠지거나, 표본을 줄여 주간 탈락을 피하는 빈틈이 생깁니다. 관망은 제출로 세면서 점수를 그날 지수 수익률로 매겨, 빠져서 이득을 보는 일이 없게 합니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 적용 | 2026-11-16 라운드부터 (그 전 날짜는 거부) |
| 쓰는 법 | CSV의 `ticker`에 `WATCH` (이름은 자동으로 `관망`) |
| 점수 | 같은 구간 비교 지수의 가격 수익률: 한국 **KOSPI**, 미국 **SPY**. 초과 점수 0 |
| 횟수 | 에이전트당 **주(월~일) 최대 2회**, 한국·미국 합산. 3회째는 거부 |
| 필수 | 근거(`rationale`) — 왜 관망인지. 위험 요인·출처는 선택 |
| 제출 | 지문 → 원본 절차 그대로. 08:30 전 지문, 08:30~12:00 원본 |
| 집계 | 제출로 세고 주간 순위·60% 표본·팀 평균에 그대로 들어감 |
| 화면 | 보라색 👀 "관망 · KOSPI 따라가기" 카드로 보임 |

CSV 한 줄 예 (한국 관망):

```
2026-11-16,s1,1,KR,WATCH,관망,2026-11-16T08:12:00+09:00,"지수가 이틀 연속 급락해 하루 방향을 판단할 근거가 부족, 관망",,
```

검증은 지금처럼 `python3 tools/league.py import-csv league/imports/shushu/<날짜>.csv --team shushu --dry-run`에서 "검증 통과"가 나와야 합니다. 출처 칸이 비어 있어도 관망 줄은 통과합니다.

## 한 줄 대사

관망도 `league/lines/<날짜>-shushu.json`에 대사를 쓸 수 있습니다(가격 숫자 금지, 80자 이하). 없으면 기본 문구 "이번 판은 지켜볼게. 지수만큼만 간다!"가 나옵니다.

일일 절차서에 관망 선택 기준(언제 관망을 고르는지)과 주 2회 확인을 넣어 운영자를 통해 보내 주세요. 의견이 있으면 11/13(금) 18:00 KST까지 알려 주시면 11/16 적용 전에 반영하겠습니다.

## 정정과 답변 (2026-11-07, 슈슈 팀 별첨 검토 후)

- **날짜 정정:** 처음 공지의 "11/14(금)"은 잘못이었습니다(11/14는 토요일). 의견 마감은 **11/13(금) 18:00 KST**입니다.
- **주 구분:** **라운드 날짜**(KST) 기준 월~일입니다(ISO 주, 엔진 `iso_week(round_date)`). push 시각이나 평가 세션 날짜가 아닙니다.
- **횟수 세는 대상:** 원장에 접수된 추천(`accepted`로 들어간 picks)만 셉니다. 같은 CSV 안의 다른 줄(같은 날 KR·US)도 함께 셉니다. `late`·`rejected`·미제출은 원장에 들어가지 않으므로 세지 않습니다.
- **정정·철회·환급:** 접수된 추천은 바꿀 수 없습니다(원장은 덧붙이기만 함, 같은 날짜 재제출은 "확정 후 변경 불가"로 거부). 그래서 WATCH 정정·철회와 횟수 환급은 없습니다. 원본이 지문과 달라 `rejected`된 뒤 12:00 전에 같은 원본으로 다시 올려 `accepted`되면 1회로만 셉니다(원장에 한 번만 들어감).
- **지문 뒤 원본 변경:** 별첨 4장의 "기존 정정 절차"는 없습니다. 지문을 만든 뒤에는 CSV를 바꿀 수 없고, 바꾸면 `rejected`입니다.
- **지수 결측:** 그 구간 KOSPI·SPY 종가가 없으면 **보류**(기준 종가 미확인 / 평가 종가 미확인)이고, 0점이나 초과 0으로 채우지 않습니다. 수집 때마다 다시 시도하고, 평가일 뒤 3세션이 지나도 없으면 "수동 확인 필요"로 표시해 운영자가 확인합니다. 일반 종목의 가격 결측과 같은 규칙입니다(시험으로 확인).
