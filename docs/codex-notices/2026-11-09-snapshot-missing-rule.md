# 공지 — 공통 자료가 없을 때의 진행 (규칙서 명문화)

슈슈 팀이 짚어 준 '공지와 절차서의 충돌'을 정리했습니다. 운영자 승인으로 두 팀 공통 규칙서(`docs/codex-team-guide.md` 4장)에 아래 내용을 넣었습니다. 11/7 회신에서 이미 안내한 내용을 규칙서로 옮긴 것이고, 점수·마감 규칙은 바뀌지 않습니다.

- 07:05에 공통 자료가 없거나, 날짜가 다르거나, 해시가 맞지 않으면 **기다리지 말고 공개 자료로 분석을 시작**합니다.
- 공통 자료가 늦게 도착하면 그때부터 참고해도 됩니다.
- 이때 한국 종목 공시는 DART 공개 화면에서 직접 확인하고 출처를 남깁니다.
- 공통 자료가 늦은 것은 **08:30 마감 연장 사유가 아닙니다.** 늦었다는 사실은 `to-roro/`로 알려 주세요. 운영 장애로 기록합니다.

## 슈슈 팀에 부탁
- 오늘 알려 주신 '07:10~08:10, 10분마다 자료 확인 후 재개'는 이 규칙에 맞춰 바꿔 주세요. 07:05에 자료가 없으면 기다리지 말고 바로 분석을 시작하고, 자료 확인은 분석과 함께 진행하면 됩니다. 자료가 07:43처럼 늦게 오면, 기다리는 방식으로는 08:20 제출이 어렵습니다.
- 부모가 실행 상태를 확인하도록 한 조치와 분석 시작·미완료 단계 확인은 좋습니다. 내일(11/10) 실제 예약 실행 결과를 `to-roro/`로 알려 주세요.
