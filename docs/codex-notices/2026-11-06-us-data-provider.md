# 슈슈 팀(Codex) 공지 — 미국 종가·배당 제공처 변경: Tiingo → Alpha Vantage (2026-11-06)

미국 종목 채점에 쓰는 종가·배당·분할 데이터를 **Alpha Vantage**에서 받기로 바꿨습니다.

## 왜 바꿨나

- Tiingo 이용약관(2026-10-06 수정)은 무료 플랜에서 점수 같은 파생 결과물을 임시로만 보관하게 합니다. 리그는 점수를 원장에 계속 저장해야 해서 맞지 않습니다.
- Alpha Vantage 무료 키는 개인·비상업 이용이고, 저장이나 계산 결과물을 막는 조항이 없습니다.
- 실제 키로 11/5 종가 수신을 확인했습니다. 배당락일 당일 배당 기록은 11/7에 확인합니다.

## 슈슈 팀이 바꿀 것

- **화면의 출처 표시만 바꿔 주세요.**
  - 전: `미국 종가·배당 — Tiingo`
  - 후: `미국 종가·배당 — Alpha Vantage`
- 한국 표시(`한국거래소 통계정보`)는 그대로입니다.
- 게임 화면 공지(2026-11-05-game-screen.md) 7장의 출처 문구도 같은 내용으로 고쳤습니다.

## 바뀌지 않은 것

- 제출 방법(지문 → 원본), 마감 시각, 파일 형식, 규칙(v1.8)은 그대로입니다.
- 점수 계산식(배당 포함 총수익, 비수정 종가 기준)과 배당 귀속 규칙(배당락일이 기준·평가 세션 사이에 있을 때)도 그대로입니다.
- 공유 결과 파일 `results.json`의 형식도 그대로입니다.
- 배당·분할을 확인하지 못한 날은 전처럼 0점이 아니라 채점 보류로 남고, 다음 수집에서 다시 채점합니다.
- 점수를 다른 사람에게 보여 주는 것은 여전히 운영자 본인 확인용으로만 합니다. Alpha Vantage 약관에서 "개인 범위를 넘는 목적"의 해석이 필요하기 때문입니다(`docs/data-provider-research.md` 10장).
